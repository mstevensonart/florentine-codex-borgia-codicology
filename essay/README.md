# The merged comparative essay (working draft space)

This file is where the expanded Borgia / Florentine Codex comparative essay gets drafted — combining:

1. The argument and structure of the 2008–09 essay, *Notes on the Codex Borgia and the Florentine Codex* (continuity of artisanal technique, pre- to post-Conquest).
2. The fuller technical detail of *"The Black, the Red": A Physical Description of the Codex Borgia* (2003 thesis / 2022 revision).
3. New supporting examples drawn from the full notebook dataset (`data/technical.json`, `data/codicology.json`) as it's completed, rather than the smaller set of illustrations cited in the original essays.

## Suggested shape

- Abstract
- Introduction (continuity thesis, methodology, manuscripts examined in person)
- Codex Borgia: support, ground, dry-media underdrawing, ink/paint, tools, color, corrections
- Florentine Codex: paper, watermarks, dry-media underdrawing, ink (European vs. native), tools, color, corrections, hand changes
- Comparative discussion: where the two manuscripts converge and diverge, and what that implies about workshop training and knowledge transmission
- Conclusion
- Notes / bibliography
